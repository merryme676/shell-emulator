# Эмулятор shell

Эмулятор командной оболочки UNIX-подобной ОС.

## Требования

- Python 3.10+
- macOS / Linux

## Запуск

```bash
./run.sh
```

Или через Makefile:

```bash
make run
```

## Параметры командной строки

| Параметр | Описание | Пример |
|----------|----------|--------|
| `--vfs`  | Путь к VFS | `--vfs vfs/test.xml` |
| `--prompt` | Приглашение | `--prompt "my> "` |
| `--script` | Стартовый скрипт | `--script scripts/start.txt` |

Пример запуска со всеми параметрами:

```bash
./run.sh --vfs vfs/test.xml --prompt "my> " --script scripts/start.txt
```

## Команды

| Команда | Описание |
|---------|----------|
| `ls`    | Заглушка (Этап 1) |
| `cd`    | Заглушка (Этап 1) |
| `exit`  | Выход |

## Тесты

```bash
make test
```

## Проверка стиля

```bash
make lint
```

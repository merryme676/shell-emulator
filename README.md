# Эмулятор shell

Эмулятор командной оболочки UNIX-подобной ОС.

## Требования

- Python 3.10+
- macOS / Linux

## Запуск

```bash
./run.sh
```

Или через Makefile:

```bash
make run
```

## Команды

| Команда | Описание |
|---------|----------|
| `ls`    | Заглушка (Этап 1) |
| `cd`    | Заглушка (Этап 1) |
| `exit`  | Выход |

## Тесты

```bash
make test
```

## Проверка стиля

```bash
make lint
```
